# مجوهرات الزهرة | إدارة الخواجة بيمن ابراهيم - أسوان
## حزمة التشغيل المباشر للاستضافات المشتركة (Shared Hosting / cPanel)

هذه النسخة مصممة خصيصاً لتعمل مباشرة على أي استضافة مشتركة (مثل cPanel أو Hostinger أو Namecheap أو GoDaddy أو أي سيرفر أباتشي/لايت سبيد) **بدون الحاجة نهائياً إلى VPS أو Node.js أو Docker أو أوامر طرفية معقدة**.

---

### محتويات الحزمة:
1. `index.php`: الصفحة الرئيسية الفاخرة المجهزة بكافة جداول العيارات والسبائك وحاسبة المصنعية.
2. `index.html`: نسخة بديلة ثابتة نقية (Pure HTML) تعمل حتى لو كانت الاستضافة لا تدعم PHP.
3. `get_prices.php`: محرك جلب ومقارنة الأسعار اللحظية (تليجرام + آي صاغة + إي دهب + الأونصة العالمية + دولار الصاغة).
4. `prices_cache.json`: ملف الكاش التلقائي اللحظي لتسريع الموقع وتفادي أي بطء.
5. `fetch_prices.py`: سكربت بايثون بديل اختياري لمن يرغب في تشغيل Cron Job مجدول.
6. `.htaccess`: ملف ضبط وتأمين وسرعة الاستضافة المشتركة.

---

### طريقة الرفع على الاستضافة (في دقيقة واحدة):
1. افتح لوحة تحكم الاستضافة (**cPanel** أو إدارة الملفات **File Manager**).
2. ادخل إلى مجلد الموقع الرئيسي: `public_html`.
3. قم برفع محتويات هذا المجلد (أو فك ضغط ملف الـ ZIP مباشرة داخل `public_html`).
4. افتح رابط موقعك في المتصفح.. **مبروك! موقعك الآن يعمل فورياً وبكامل ميزاته.**
